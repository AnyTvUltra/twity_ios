# مواصفات أشكال وأحجام عناصر لعبة الكونكان (Okey) — لبناء السكنات

> الهدف: تصميم **سكنات (Texture/Skin)** تُلبَس فوق القطع الموجودة — **وليس** تصميم قطع جديدة.
> كل سكن هو صورة PNG/WebP (أو Sprite Sheet للمتحرك) تُطبع فوق الشكل الحالي بنفس القصّة والنسبة.
> الأرقام والأيقونات والحدود تُرسم فوق السكن في الكود — فصمّم السكن بحيث يبقى مركز الحجر مقروءاً.

---

## 1. حجر الأوكي — `OkeyTileWidget`

### النسبة والحجم
- **نسبة العرض إلى الارتفاع: `1 : 1.36`** (العرض × 1.36 = الارتفاع)
- الحجم داخل اللعبة: `26×36` على طاولة البيرات، وحتى `38×52` على الاستكانة
- **الملف المطلوب: `240×327 px`** (نسبة 1:1.36 — جودة ×6.3 للـ Retina)

### الشكل (واجهة أمامية مسطحة مع حافة سفلية)
- مستطيل عمودي **بزوايا دائرية radius = 9% من العرض** (≈22px على ملف 240×327)
- بنية الحجر من الأعلى للأسفل:

```
┌─────────────────────┐  ← 0%
│   لمعان علوي أبيض   │  ← يُرسم تلقائياً فوق السكن (أعلى 35% من الارتفاع)
│                     │
│       [ الرقم ]     │  ← الرقم يُرسم فوق السكن، حجمه = 52% من العرض، بالمنتصف
│         ●           │  ← نقطة لونية تحت الرقم = 14% من العرض
│                     │
│ ▓▓ حافة سفلية داكنة │  ← آخر 2px (~2.5%) تُعتّم تلقائياً لإحساس السماكة
└─────────────────────┘  ← 100%
```

### قواعد التصميم للحجر
- السكن يغطي **كامل الوجه** (100%×100%) مع قصّ الزوايا الدائرية تلقائياً
- **اترك المنطقة المركزية (الـ60% الوسطى) هادئة/فاتحة** — الرقم والنقطة يُرسمات فوقها بألوان (أحمر/أزرق/أسود/أصفر)
- تجنّب نصوصاً أو تفاصيل في المركز — ستُغطى بالرقم
- حدود الحجر تُرسم برمجياً (ذهبي عند التحديد، برتقالي للجوكر الحقيقي) — لا ترسم حدوداً سميكة في السكن
- النسخة الافتراضية: إيفوري `#FFFDF8 → #F3EAD5` — السكن الجيد يحاكي هذه الفاتحة أو يتعمد الداكن مع تباين

## 2. الاستكانة — `OkeyIstakaWidget`

### البنية الدقيقة (وحدات منطقية)
الاستكانة جسم مستطيل واحد يحمل **صفّين × 14 خانة**. من الأعلى للأسفل:

```
┌────────────────────────────────────────────┐
│  لوح خلفي علوي (ارتفاع 20)                 │ ← شريط مائل/ظل
│  ┌──────────────────────────────────────┐  │
│  │ صف علوي: 14 خانة (ارتفاع = حجر 1.36) │  │  هامش جانبي 14
│  ├──────────────────────────────────────┤  │
│  │  حاجز خشبي (ارتفاع 4 + هامش 5)       │  │  ← فاصل الصفين
│  ├──────────────────────────────────────┤  │
│  │ صف سفلي: 14 خانة (نفس الارتفاع)      │  │
│  └──────────────────────────────────────┘  │
│  شفة سفلية (ارتفاع 4)                      │ ← حافة بارزة
└────────────────────────────────────────────┘
 ▲                                          ▲
 غطاء جانبي مثلث (عرض 12) — يسار ويمين
```

### الحجم
- العرض = `14 × عرض_الخانة + 28 + 24` — عند أقصى حجم (خانة 40): **612 وحدة منطقية**
- الارتفاع الكلي ≈ `20 + 4 + 52 + 9 + 52 + 4 + 4` ≈ **145 وحدة منطقية**
- **الملف المطلوب: `1224×290 px`** (×2 للجودة)
- زوايا دائرية `radius = 5` وحدات (10px على الملف)
- الغطاءان الجانبيان المثلثان يُرسم فوق طرفي السكن — اجعل الطرفين داكنين/محايدين

### قواعد التصميم للاستكانة
- السكن يغطي **الجسم كاملاً** بما فيه منطقة الأحجار (الأحجار تُرسم فوقه)
- طبقة تعتيم سوداء 12% تُرسم فوق السكن تلقائياً
- **الأهم:** منتصف الصورة سيكون مخفياً خلف الأحجار — ركّز الجمال على **اللوح العلوي (أعلى ~14%)** و**الحاجز الأوسط** و**الشفة السفلية** — هذه الأجزاء تبقى ظاهرة دائماً
- الخشب الافتراضي: `#5A2E16 → #241006` بني داكن — حاكِه أو اِتجَه للمعدن/الرخام/النار/الجليد
- استكانات الخصوم تستخدم **نفس السكن** مصغّرة — يجب أن يبدو جيداً عند تصغيره لـ30%

## 3. منطقة البيرات على الطاولة — `StoreCategory.table`

- أحجار البيرات النازلة: `26×36` (نفس نسبة الحجر)
- سكن الطاولة = **نسيج السطح اللعب** الذي تُرسم عليه الأحجار (مخمل/رخام/ماء)
- **الملف المطلوب: `2048×1152` أو `2048×2048`** — يُطبع على المساحة الأمامية من الطاولة بقصّ مستطيل بزوايا دائرية
- يجب أن يكون النسيج **داكناً هادئاً** حتى تبرز الأحجار الفاتحة فوقه (تباين)
- تجنّب خطوطاً أو نقوشاً كبيرة — الأحجار الصغيرة تضيع عليها

---

## 4. الخلفية — `StoreCategory.background`

- تملأ **كامل المشهد** خلف الطاولة والاستكانات (cover crop)
- **الملف المطلوب: `2160×1080` أفقي** (تُقصّ حسب اتجاه الجهاز — أفقي وعمودي)
- اجعل المركز أغمق/أهدأ — الطاولة والأحجار فوقه
- الهوية: كحلي/بنفسجي داكن `#1A0B2E → #0D0618` — أي خلفية يجب أن تحافظ على إبراز الطاولة الخضراء/الداكنة

---

## 5. إطار الصورة الشخصية — `StoreCategory.frame`

### الشكل
- **حلقة دائرية** حول صورة دائرية — مركز الإطار **شفاف تماماً**
- نصف قطر الحلقة الداخلي ≈ **70% من نصف قطر الصورة**، والزخرفة في الحلقة الخارجية 30%
- على ملف `512×512`: الحلقة المرئية بين نصف القطر **~178px و~256px**، والداخل Ø≈356 شفاف

```
        ╭──────────╮
      ╱   زخرفة    ╲       ← الحلقة الخارجية: النار/الجليد/الذهب هنا
     │  ╭────────╮  │
     │  │        │  │      ← داخل الحلقة: شفاف 100% (صورة اللاعب)
     │  ╰────────╯  │
      ╲   زخرفة    ╱
        ╰──────────╯
```

- **الملف المطلوب: `512×512` PNG بألفا** — مركز شفاف، زخرفة على المحيط فقط
- يمكن تجاوز الحواف قليلاً (شرارات/سنابل تخرج من الحلقة) — ضعها في آخر 10% من الأطراف

## 6. السكنات المتحركة — Sprite Sheet

كل تأثير متحرك = **شريط فريمات أفقي** بنفس أبعاد السكن الثابت:

| العنصر | ملف الفريم الواحد | فريمات مقترحة | fps |
|---|---|---|---|
| حجر | `240×327` لكل فريم | 16–24 | 18–24 |
| استكانة | `1224×290` | 12–16 | 15–20 |
| إطار | `512×512` | 24 | 20–24 |
| طاولة | `2048×1152` | 12 | 12–15 |

- الشريط = فريمات متجاورة أفقياً في ملف واحد: `fire_tile_24f.png` بعرض `24 × 240 = 5760px`
- **شرط الحلقة السلسة: آخر فريم يجب أن يلتقي بالأول بلا قفزة** (تدرّج/جزيئات دورية)
- أو بدلاً منه **Lottie JSON** — يُفضَّل للإطارات (ملف صغير، جودة لانهائية)

## 7. Manifest — لكل سكن ملف JSON

```json
{
  "id": "fire_tile_01",
  "name": "أحجار النار",
  "category": "tile",
  "type": "spritesheet",
  "file": "fire_tile_24f.png",
  "frames": 24,
  "fps": 20,
  "loop": true,
  "zoom": 1.0,
  "offsetX": 0,
  "offsetY": 0,
  "price": 40,
  "currency": "gems"
}
```

- `category`: `tile` | `rack` | `table` | `background` | `frame` | `chessBoard` | `chessPieces`
- `type`: `static` | `spritesheet` | `lottie`
- `currency`: `chips` | `gems`

## 8. قائمة تدقيق قبل التسليم

- [ ] حجر: 240×327، زوايا ~22px، مركز نظيف للرقم، لا حدود مرسومة
- [ ] استكانة: 1224×290، الجمال في الأطراف الظاهرة (علوي/فاصل/سفلي)
- [ ] طاولة: نسيج داكن هادئ 2048×1152
- [ ] خلفية: 2160×1080 بمركز هادئ
- [ ] إطار: 512×512 مركز شفاف Ø356، زخرفة في الحلقة الخارجية
- [ ] متحرك: فريمات loop متصلة، أو Lottie
- [ ] JSON manifest لكل ملف
